🧠 TaskMind API Console

Локальная консоль для ручной проверки REST API проекта. Работает поверх запущенного сервера (mvn quarkus:dev, порт 8080) — открой её как http://localhost:8080/, тогда все запросы идут с того же источника и CORS не мешает.
Из сида гарантированно логинится только admin / admin123 — у остальных пользователей (dev_anna, designer_max, tester_olga) в базе фиктивный хеш пароля. Для проверки от лица «обычного» пользователя используй кнопку «Зарегистрировать тестового юзера».
У всех DELETE-запросов поле id намеренно пустое (серым показан лишь пример) — впиши id осознанно, чтобы не снести сид-данные одним кликом. После входа токен подставляется в заголовок Authorization всех остальных запросов автоматически.
TaskMind API Console · генерируется из api.rest + api.dto, актуально на момент создания файла
